## Admin Attributes Page — Section Separation & Layout Redesign

### Problem (from your screenshot + code review)

1. **Cramped/merged sections** — On the Ring attribute page, 5 major attribute groups (Size Choice Cards, Metal Options, Band / Claw Metal Options, Ring Style Showcase, Engagement Rings — Shop by Style, Wedding Rings — Shop by Style) all render as plain `<div class="admin-field admin-field-full">` elements inside a single `.admin-grid.two-up` inside one outer `.admin-product-card`. Each group has an identical `--panel-soft` grey background and only ~12px of gap. Result: they read as one continuous grey form, not clear separate sections.

2. **Empty right column** — `.admin-product-editor` declares `grid-template-columns: minmax(0, 1.55fr) 330px` always, reserving a 330px sidebar column. But for all "matrix" types (Ring, Earring, Necklace, Bracelet, Pendant), the `<aside class="admin-product-sidebar">` is suppressed by `if (!$attributeTypeIsMatrix)` at `admin/index.php:5379`. So the 330px column is allocated but never filled — pure whitespace on the right.

### Implementation

**File 1 — `admin/index.php`** (small PHP-markup changes, no flow/logic edits):

A. At line 5160, render `<div class="admin-product-editor<?= $attributeTypeIsMatrix ? ' admin-product-editor--single' : '' ?>">` so matrix pages get a full-width layout class.

B. Inside the single `.admin-product-card` at lines 5162–5377, replace each `<div class="admin-field admin-field-full">` group wrapper with `<section class="admin-attr-group admin-field admin-field-full">`. This is a pure markup wrapper change — the input names, repeaters, templates, `data-*` attributes, and form action all stay untouched.
   - Affected groups: `Size / Weight Choice Cards`, `Metal Options`, `Band / Claw Metal Options`, `Ring Style Showcase`, `Engagement Rings — Shop by Style`, `Wedding Rings — Shop by Style` (and the non-ring "Style Showcase" branch at line 5339).
   - Also give each group a numbered badge label (e.g. `<span class="admin-attr-group-num">01</span>`) before the existing title `<span>`, purely for visual hierarchy.

**File 2 — `assets/css/admin.css`** (append ~80 new lines at the end, scoped only to the admin page; no existing rules deleted):

